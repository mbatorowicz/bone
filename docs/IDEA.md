# Bone SR — kanon

## Teza

**Czysta grawitacja N-ciał z kinematyką szczególnej teorii względności w otwartej przestrzeni.**

Bez ścian-klatki. Bez warstwy społecznej (bond / wealth / trade…).

## Dynamika

- Masa spoczynkowa \(m\).
- Pęd \( \mathbf{p} = \gamma m \mathbf{v}\), \(\gamma = 1/\sqrt{1-v^2/c^2}\).
- Leapfrog: \(\mathrm{d}\mathbf{p}/\mathrm{d}t = \mathbf{F}\), \(\mathbf{v} = \mathbf{p}\,c^2/E\).
- Siła: przyciąganie Newtonowskie na \(m_i m_j\) (softened) + lekkie odpychanie jądra.

## Start

10 brył: `cube_cloud`, `sphere_shell`, `ball`, `disk`, `filament`, `two_clumps`, `lattice`, `gaussian`, `donut`, `sphere_band`.

Presety: **Galaktyka** (torus+orbit), **Gromada** (zimna kula), **Burst SR** (wysokie \(v/c\)).
